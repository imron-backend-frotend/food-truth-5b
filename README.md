# Школьный исследовательский проект: «Неправильная пища: ловушка вкуса»

**Автор проекта:** Раимов Ихлас  
**Класс:** 5 «Б» класс  
**Год создания:** 2026  
**Тема:** Исследование влияния фастфуда, сладких газированных напитков и снеков на здоровье школьников.

---

## 📌 О проекте

Современный интерактивный веб-сайт, созданный для наглядной защиты школьного исследовательского проекта по окружающему миру, биологии и здоровому образу жизни (ЗОЖ). 

### 🌟 Что включено в сайт:
1. **Интерактивный классификатор вредной пищи:**
   - Детальный разбор чипсов, газировок, энергетиков, бургеров, сладостей и сосисок.
   - Описание скрытых угроз: трансжиры, акриламид, ортофосфорная кислота, нитриты, глутамат натрия.
2. **Интерактивный Сахаромер:**
   - Наглядная 3D-визуализация выпадающих кубиков сахара в стакан для популярных напитков (Кола, пакетированный сок, энергетик, молочный коктейль, чистая вода).
   - Сравнение с суточной нормой пятиклассника (25г / 5-6 кубиков).
3. **Анатомическая интерактивная карта:**
   - Кликабельные органы (мозг, зубы, желудок, сердце, кожа, печень).
   - Объяснение эффекта «сахарных качелей» и снижения концентрации на уроках.
4. **Калькулятор «Цена перекуса» (Фитнес-счётчик):**
   - Выбор любимых снеков и мгновенный подсчёт: сколько кругов по школьному стадиону (400м) или минут на велосипеде нужно, чтобы сжечь калории.
5. **Практическое исследование 5 «Б» класса:**
   - Интерактивная диаграмма опроса 26 одноклассников.
   - Описание наглядных опытов Ихласа (опыт с чипсами и жиром на фильтровальной бумаге, опыт с колой и ржавой монеткой).
6. **Таблица крутых здоровых замен:**
   - 6 готовых рецептов полезных школьных перекусов (чипсы из лаваша, домашний лимонад, сэндвич с индейкой, орехово-финиковые батончики и др.).
7. **Тест-викторина «Знаток здорового питания»:**
   - 5 вопросов с мгновенной проверкой, пояснениями и праздничным салютом (конфетти).
   - Выдача именного сертификата отличника ЗОЖ.
8. **Памятка для распечатки:**
   - Поддержка печати через кнопку «Распечатать памятку» (`Ctrl + P`) со специальными стилями для формата А4.

## 🚀 Как запустить сайт

### Вариант 1 (Самый простой):
Просто дважды кликните по файлу `index.html` в проводнике Windows — сайт откроется в вашем любимом браузере (Chrome, Edge, Яндекс.Браузер, Firefox). Подключение к интернету нужно только для загрузки красивых иконок и шрифтов.

### Вариант 2 (Локальный сервер):
Сайт уже запущен на локальном сервере по адресу:
👉 **http://localhost:8080**

## 📂 Структура файлов проекта:
- `index.html` — основная разметка и структура всех интерактивных блоков.
- `style.css` — стили, эффекты стекла, кубики сахара и стили для печати памятки.
- `app.js` — логика калькулятора, сахаромера, анатомической карты, графика опроса и викторины с конфетти.
